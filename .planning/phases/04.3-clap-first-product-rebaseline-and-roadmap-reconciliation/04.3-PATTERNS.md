## Shared Patterns

### Confirmed-scope gating (V4 access control)
**Source:** `daemon/src/peers/action-dispatch.ts` lines 35–40; `daemon/src/peers/telemetry-dispatch.ts` lines 15–17 (`try { registry.requireConfirmed(...) } catch { return false; }`)
**Apply to:** every new ingress — arrangement review requests from the editor included. Unconfirmed → `action.error scope_not_confirmed`; changed focus → `scope_mismatch`. Names are never authority.

### Bounded failure surfacing (never crash, never leak)
**Source:** `daemon/src/peers/action-dispatch.ts` lines 19–25 + 49–53 (`analysisErrorCode` maps `PiRuntimeFailure` codes → `analysis_auth_required`/`analysis_model_unavailable`/`analysis_proposal_required`/`analysis_failed`; raw SDK strings never cross the peer boundary)
**Apply to:** the deterministic render path must work with no provider configured (locked local-first decision); provider failures remain Pi-turn-scoped only.

### Freshness + pulledAt honesty (stale-evidence defense)
**Source:** `daemon/src/query/query-server.ts` — `pulledAtAssumption` lines 872–885, disconnected refusal lines 903–910 and 1107–1110, `safeSendOk`/`safeSendErr` envelope (`stateFreshness` field) lines 1285–1339
**Apply to:** every rendered arrangement group carries its `pulledAt` assumption; hard-refuse grid renders when disconnected + fresh pull requested.

### Advisory discipline (grep-enforceable)
**Source:** `daemon/src/transforms/transition-suggest.ts` lines 11–18 (no patchId/operations/risk; MUST NOT import `../patch/*`) + `query-server.ts` lines 1068–1079 (T-04-16 comment)
**Apply to:** the render module and any evidence surfaced in the conversation pane. Escalation to mutation only via Analyze → `preview_edit` → `create_proposal` → approval → controller `apply.patch`.

### Targeted peer sends (ROUTE-1)
**Source:** `daemon/src/runtime/boot.ts` line 440/470 (`sendTo: (connectionId, message) => peers.registry.sendTo(connectionId, message)`)
**Apply to:** chunk emission — every `conversation.chunk` names one authorized confirmed connectionId; no broadcast.

### Native bounded decoding (V5)
**Source:** `clap/src/model/UiState.cpp` — fail-closed property helpers (lines 39–65), 65'536 message cap (line 31), explicit limit checks (`text.size() > 512`, revision ranges)
**Apply to:** the extended `conversation.chunk` decoder (requestId/sequence parsing) and any new UiAction encoding — limit+1 negative tests mandatory.

### Frozen-schema discipline (only if schemas are touched — recommended NOT this phase)
**Source:** RESEARCH Pattern 5 / `04.2-PATTERNS.md` Pattern 2: schema edit → `npm run gen:types` → commit generated output → golden fixtures → C++ bounded decoder + limit+1 negatives → drift gate (`git diff --exit-code -- ../schemas src/gen`)
**Apply to:** choosing `conversation.chunk` reuse avoids this entirely.
