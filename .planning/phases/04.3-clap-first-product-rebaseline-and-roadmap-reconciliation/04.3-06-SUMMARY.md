## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] BankSyncWait.Sleeper replaces the planned java.util.function.LongConsumer sleeper parameter**
- **Found during:** Task 1 (BankSyncWait creation)
- **Issue:** The plan specified `a java.util.function.LongConsumer sleeperMs` (Task 1 action) AND `Thread::sleep for sleeperMs` (Task 2 action) — these are mutually incompatible: Thread.sleep(long) throws checked InterruptedException, and LongConsumer.accept(long) declares no throws, so the method reference `Thread::sleep` cannot target LongConsumer (compile error). A LongConsumer + wrapping lambda would also busy-spin to the 5s cap after an interrupt (Thread.sleep throws immediately while the flag is set).
- **Fix:** Introduced `BankSyncWait.Sleeper` (`void sleep(long ms) throws InterruptedException`) so production binds `Thread::sleep` verbatim as planned; awaitSettled catches InterruptedException, restores the interrupt flag, and returns waited — honest proceed, never hang, never throw into the void. Test fakes (lambdas) are unaffected.
- **Files modified:** bridge/src/main/java/com/bwbrain/bridge/BankSyncWait.java
- **Verification:** 51/51 bridge tests green; production wiring compiles with the verbatim Thread::sleep method reference (PullHandlers.java:544)
- **Committed in:** f85eea7 + 24f3b17
