Implement `section-detector.ts` as a PURE module + Analyzer plugin.

1. **Pure clustering helper `agglomerativeBoundaries(features, sim, opts?)`**: contiguous agglomerative clustering (D-14). Start with N single-scene clusters. Iteratively merge the ADJACENT pair (only clusters sharing a boundary) with the highest cosine affinity (from the `sim` matrix) until (a) `maxSections` clusters remain (default 8), OR (b) the best merge affinity drops below `minSimilarity` (default 0.6 — D-14). Return `SceneBoundary[]` = `[{startScene, endScene}, ...]` covering [0, n-1] with no gaps/overlaps. The Ward-style "minimize within-cluster variance" maps to "merge the adjacent pair with highest mean intra-cluster affinity" — the structural analog is the argmax loop in `harmonic-detect.ts:99-116`. ~40-50 lines.

2. **Pure labeler `labelSections(boundaries, features, profile)`**: map each boundary to a genre-profile label. Compute the section's mean energy (from features) + position (start/middle/end relative to scene count). Match against `profile.sectionLabels` (from Plan 02): find the label whose `energyRange` contains the section's energy AND whose `position` matches. Below-threshold / no match → label `"unknown"` (refuse — Pitfall 7). Return `SectionSummary[]` = `[{startScene, endScene, label, avgSimilarity, energy, confidence}]`. Confidence = mean intra-section similarity (honest ∈ [0,1]; do NOT pre-floor — Pitfall 4; runAll floors at 0.5).

3. **Analyzer wrapper `SectionDetector`**: copy the `MotifSignatureAnalyzer` shape (motif-signature.ts:170-193). `id: "sections"`, `consumes: ["clips"]`, `produces: ["sections"]`. In `analyze(raw, ctx)`: defensively extract the launcher grid from `raw` (the snapshot mirror); if no grid or 0 scenes → return `[]` (refuse). Compute `sceneFeatureVector` per scene (Plan 02), `selfSimilarityMatrix` (Plan 02), `agglomerativeBoundaries`, `labelSections`. Return `[{field:"sections", value: sections, confidence: minSectionConfidence, assumptions: [{claim:"derived from N scenes via cosine-affinity agglomerative", confidence:1.0, source:"default"}, {claim:"profile: <name>", confidence:1.0, source:"config"}]}]`.

Type-only import from `../state/analyzer-registry.js` (no cycle — mirrors motif-signature.ts:20-25). NodeNext ESM `.js` imports throughout.
