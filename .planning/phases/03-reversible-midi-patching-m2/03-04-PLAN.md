## Phase Goal

**As a** producer, **I want to** generate motif-preserving A/B/C MIDI variants and low-risk cleanups, **so that** creative transforms lean on the trust spine (Plan 01/02) without ever degrading into casino MIDI.

## Plan Objective (vertical slice 4: creative + cleanup MIDI transforms)

Plans 01–03 shipped the trust spine + musical-knowledge foundation. This plan ships the **four MIDI transforms** that mint candidate patches through that spine: `vary` (MIDI-02, creative), `counterline` (MIDI-03, creative), `voice-leading-fix` (MIDI-04, cleanup), `humanize` (MIDI-05, cleanup) — wired into `bw-midi` + the daemon `midi.*` dispatch. After this plan: a producer can run `bw-midi vary` and get 3 motif-preserving A/B/C candidates (each a candidate-store patchId), and the cleanup transforms produce low-risk patches that never refuse on motif grounds.

**Purpose:** MIDI-02/03/04/05. Creative transforms run the full motif gate (refuse + near-miss per D-08/09/10); cleanup transforms skip the gate (INV-8). Pitch changes are always remove+add (Pitfall 2).
**Output:** vary.ts, counterline.ts, voice-leading-fix.ts, humanize.ts + tests (INV-7,8,11 + boundary); midi.ts extended with 4 subcommands; query-server midi.* dispatch.
