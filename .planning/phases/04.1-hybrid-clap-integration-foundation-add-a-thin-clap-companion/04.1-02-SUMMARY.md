## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Packaged the probe as a macOS CFBundle**
- **Found during:** Task 1 validator verification
- **Issue:** A raw `.clap` shared module could not be opened by the macOS validator.
- **Fix:** Applied the official CLAP bundle properties and plist template to produce `Contents/MacOS` packaging.
- **Files modified:** `clap/CMakeLists.txt`
- **Verification:** Pinned validator opened and validated the bundle.
- **Committed in:** `0769dd1`

**2. [Rule 1 - Bug] Prevented transport-event echo**
- **Found during:** Task 1 validator verification
- **Issue:** Forwarding every core event echoed host transport events, which CLAP forbids.
- **Fix:** Restricted forwarding to note, note-expression, MIDI, SysEx, and MIDI2 events while retaining original headers/sample offsets.
- **Files modified:** `clap/spike/CapabilityProbePlugin.cpp`
- **Verification:** `transport-fuzz-sample-accurate` passes.
- **Committed in:** `0769dd1`

**3. [Rule 1 - Bug] Made state strict, buffered, and parameter-complete**
- **Found during:** Task 1 and Task 2 validator verification
- **Issue:** Unframed state accepted random bytes; single-write state failed buffered streams; parameter values were not restored or rescanned.
- **Fix:** Added deterministic magic/version framing, bounded reads, partial-write handling, persisted parameter values, and host value-rescan notification.
- **Files modified:** `clap/spike/CapabilityProbeProcessor.cpp`, `clap/spike/CapabilityProbePlugin.cpp`
- **Verification:** All invalid-state and state-reproducibility validator tests pass.
- **Committed in:** `0769dd1`, `987ff0f`

**Total deviations:** 3 auto-fixed (2 bugs, 1 blocking issue). **Impact:** Required for a truthful validator-clean capability probe; no product scope was added.
