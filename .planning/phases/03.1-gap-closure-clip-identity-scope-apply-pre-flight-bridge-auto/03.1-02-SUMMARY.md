## Decisions Made

- **V1 over V2:** the javap finding (Clip has setName but no name() reader in extension-api:21) is permanent, so the launcher-clip-name accessor path is closed. V1's `trackSid:loopBeats` hash is the honest minimum. V2 (add `color()` or `ClipLauncherSlotBank` scene-index for same-length-same-track disambiguation) is deferred per RESEARCH §D-01(c); the documented residual risk is same-track-same-length collision, which is not within-selection ambiguous (cursor sits on one clip at a time).
- **Push/pull input symmetry:** the bridge caches `cursorTrackName` in `Observers.java` (volatile field) and reads it in BOTH the push observer (wireCursorClip) and the pull handler (handleSelectedClip via `observers.getCursorTrackName()`). This makes the two paths mechanically agree on the hash inputs — no daemon-side reconciliation needed.
- **Raw track name vs sid as hash input:** the bridge cannot reach the daemon's STATE-04 sid map, so for V1 it passes the RAW cursor track name to `ClipSid.derive`. The daemon treats the bridge-supplied clipSid as OPAQUE (schema pattern-checks the output only; never re-derives). This means same-named tracks across projects would collide on the trackSid INPUT — but the daemon never compares inputs, only outputs, so the apply pre-flight still catches wrong-clip targeting (different bridge-supplied clipSids → mismatch refused).
- **D-03d shipped:** RESEARCH Open Question 1 resolved in favor of including the optional `get.selected_clip` pull in `refreshSnapshot` — low-risk, additive, makes the pre-flight robust on cold reconnect. CONTEXT.md's claim that refreshSnapshot already pulled it was corrected (Pitfall 3).
- **Auto-approve Task 3:** per `auto_advance: true` + `human_verify_mode: "end-of-phase"`, the live-Bitwig checkpoint is deferred to the end-of-phase UAT. The JUnit ClipSidTest already proves the load-bearing invariants (determinism + pattern + M4-failure-mode); the live verification validates Assumption A2 (`getLoopLength().get()` reads reliably on a live cursor clip).
