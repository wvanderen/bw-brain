**The hash construction (D-01 V1, from RESEARCH §D-01(a) Example 1):**
```java
// "clip_" + sha256(`${trackSid}:${loopBeats}`).slice(0,16) — matches ^clip_[0-9a-f]{16}$.
public static String derive(final String trackSid, final double loopBeats) {
    final String input = trackSid + ":" + loopBeats;
    try {
        final byte[] hash = MessageDigest.getInstance("SHA-256")
                .digest(input.getBytes(StandardCharsets.UTF_8));
        final String hex = HexFormat.of().formatHex(hash).substring(0, 16);
        return "clip_" + hex;
    } catch (final Exception e) {
        return "clip_0000000000000000"; // unreachable (SHA-256 is JDK-guaranteed)
    }
}
```

**Loopback/format invariants (must not violate):**
- Output MUST match `^clip_[0-9a-f]{16}$` — see `schemas/project-state.schema.json:63` for the frozen pattern.
- `trackSid` itself is the parent track's STATE-04 fingerprint (`^trk_[0-9a-f]{16}$`); pass `cursorTrackName` already-fingerprinted, NOT raw.

**Error handling:** fall back to `"clip_0000000000000000"` (still pattern-valid) so the daemon's Ajv gate accepts the line and the pre-flight catches any mismatch. Don't propagate `NoSuchAlgorithmException` — SHA-256 is JDK-guaranteed.
