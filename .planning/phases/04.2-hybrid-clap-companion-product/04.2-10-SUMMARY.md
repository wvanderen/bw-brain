## Accomplishments

- Added immutable reducer snapshots for connection, link, scope, session, conversation, proposal, approval, scheduler, drops, countdown, and errors.
- Added a visible context/conversation/proposal workspace with the proposal drawer absent until inspectable material exists and explicit link, focus, fork, approval, arm, Analyze, and Stop actions.

## Decisions Made

- Kept all hosted actions outside CLAP automation and persisted only the instance-local musical value.
- Used a strict bounded mutex queue for non-RT UI commands; no editor code sees sockets, daemon services, scheduler objects, or mutation handles.
- Kept Stop independent of visible focus so it reaches every confirmed instance in the named project.
