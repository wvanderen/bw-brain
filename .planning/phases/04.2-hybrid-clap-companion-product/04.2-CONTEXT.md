# Phase 04.2: Hybrid CLAP Companion Product — Context

**Status:** Blocked / unplanned until Phase 04.1 completes
**Depends on:** Phase 04.1 CLAP Capability & Host Evidence Gate

## Phase Boundary

Build the production companion only after Phase 04.1 records resolved Q1–Q4 evidence. The daemon owns project/session/focus/proposal/routing authority; the Java controller remains the only existing-project mutation adapter; CLI remains stable; Pi remains external; CLAP owns signal-local observation and exact approved phrase playback only.

## Locked Product Decisions

- **D-01:** Full plug-in window is a focused musical decision workspace.
- **D-02:** Compact context strip, central conversation, conditional proposal drawer.
- **D-03 (superseded 2026-08-10 by accepted Phase 04.1 Q3 evidence):** Bitwig's device panel exposes read-only connection/session status, read-only proposal-pending indication, and ordinary automatable musical controls. Analyze and Stop are always available as non-recording actions in the hosted CLAP UI; they are not disguised as automatable parameters. Phase 04.1 proved the non-automatable Analyze parameter was absent from Bitwig's device panel while the hosted editor worked, so this evidence-driven contract supersedes the pre-gate wording without changing requirement ID D-03.
- **D-04:** Quiet startup performs connection/identity only; no automatic reasoning.
- **D-05:** Continuous lightweight local telemetry; reasoning only on demand.
- **D-06:** Note events and bounded aggregates may leave; raw audio never leaves or persists.
- **D-07:** Only inspected, explicitly armed, bounded live MIDI may play.
- **D-08:** Disconnect preserves original signal and safely stops generated material with note-offs.
- **D-09:** One daemon-owned Pi session per project; many instance contexts.
- **D-10:** Persistent instance ID plus controller/daemon correlation and one-time confirmation; names are not authority.
- **D-11:** Focused-instance targeting is explicit and visible.
- **D-12:** Reopen resumes, duplicate rekeys, Save As forks project-local session history.
- **D-13:** UI approves; existing controller/candidate/pre-flight/journal path mutates.
- **D-14:** Exact approved live MIDI arms then launches at the configured beat/bar boundary.
- **D-15:** Approval is one-shot and exact-revision/project/instance/clip scoped.
- **D-16:** Global Stop cancels generated behavior and disarms without reverting journaled edits.
